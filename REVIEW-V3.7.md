# Feedboard V3.7 — рабочая версия для согласования

Основа: V3.6.3, commit d3719f5bbf51af310dfa57d0ade8967ef12f6828.
Рабочая ветка: work/v3.7-ux. Резервная: backup/v3.6.3-before-v3.7.
Основной сайт не обновлен. Номер в интерфейсе: V3.7 preview.

## Изменения
- Основная сетка: прежние 3:4 и три колонки, углы без скругления, промежуток 2 CSS px. Прежнее кадрирование сохранено.
- Reels: фильтр тех же публикаций, 9:16, центральная область исходной обложки без применения кадрирования основной сетки. Только изображения. Перестановка меняет позиции Reels среди их прежних мест, остальные публикации остаются на месте.
- SVG-значки по согласованному образцу. Типы: Пост / Карусель / Обложка Reels.
- Вместо удаления всей сетки при каждом сохранении — повторное использование существующих карточек, изображений и URL. Кадрирование применяется к актуальной записи. Неизмененные миниатюры карусели тоже сохраняются. Исправлено позиционирование изображения в копии карточки при перетаскивании.
- Отмена последнего удаления в текущем сеансе (до следующего удаления, импорта, очистки проекта или закрытия приложения). Восстанавливает слайды, кадрирование и место. Можно отменить из другого проекта. Конфликт с другим окном блокирует восстановление, не затирает его изменения.
- Переименование трех проектов до 30 символов. Внутренние ID остаются прежними. Названия записаны отдельно в существующем хранилище meta, без изменения версии базы; записи V3.6.3 не стирают их.
- Копии версии 1 включают необязательное поле projectNames. Старые копии восстанавливаются с исходными названиями Personal / Project 1 / Project 2. Все прежние проверки изображений и атомарное восстановление сохранены.
- Видимая ссылка на резервное копирование; повторное скачивание каждый раз создает свежий временный URL. Кнопка закрытия сообщения сохранена.
- Минимальная высота небольших управляющих кнопок 44 px; длинные названия проектов сокращаются визуально, полное имя доступно для чтения и переименования.

## Без изменений
Цвета, логотип, Manrope, темы, число проектов, схема фотографий, DB_VERSION=2, локальное хранение, отсутствие сервера и видео. Существующие фото не преобразуются. Подготовка новых загружаемых фото до 2000 px работает как раньше.

## Проверки
Команды из корня репозитория (зависимости только тестовой среды, не приложения):
```
FEEDBOARD_SOURCE=index.html node tests/regression.cjs
FEEDBOARD_SOURCE=index.html node tests/import-conflicts.cjs
FEEDBOARD_SOURCE=index.html node tests/ux-v37.cjs
```
Среда тестов: Node, jsdom, fake-indexeddb; адаптер декодирования изображений sharp. Приложение не использует эти библиотеки.
17 прежних регрессионных + 19 проверок импорта/конфликтов + 19 новых UX/хранения = 55 успешных сценариев.
Проверено: все три проекта, добавление, удаление, порядок, карусели, типы, кадрирование, повторное открытие, точные байты экспорта, старые/новые копии, поврежденные файлы, откат транзакции, одновременные импорты, устаревшие вкладки, переименование, отмена удаления и повторное скачивание.
Изменение размеров 320 / 375 / 390 / 412 / 1440 проверено только на вызовах обработчиков DOM и смене темы, НЕ на реальном расчете верстки.

## Ограничения проверки
Локальный Chromium не запустился. Удаленный браузер не имеет доступа к локальному серверу; открытие файлов запрещено его политикой. Визуальная проверка на iPhone, Android и компьютере не завершена. Жесты и исчезновение мерцания на настоящем iPhone еще нужно подтвердить. Сравнение PNG — схема по коду с присланными референсами, не снимки браузера.
3:4 задано пользователем и уже использовалось в V3.6.3. 9:16 соответствует измерениям присланного скриншота вкладки Reels (примерно 236x420 px). Официальные страницы Instagram о пропорциях изображений и Reels не удалось прочитать (HTTP 429). Независимое подтверждение именно геометрии вкладки официальной документацией не получено; формат видео не выдается за размер миниатюры.

## Перед выпуском: проверка на устройствах
1. На отдельной тестовой установке/адресе восстановить копию с тестовыми фотографиями. Не импортировать поверх нужных данных.
2. Проверить светлую и темную темы на узком экране: три колонки, нет горизонтальной прокрутки, кнопки помещаются.
3. Создать пост, карусель и обложку Reels. Перетащить в основной сетке и Reels; проверить соответствие порядка после повторного открытия.
4. Проверить обложку с нестандартными пропорциями: в основной сетке сохраненное кадрирование, в Reels центральное отображение 9:16; файлы не растянуты.
5. Удалить карусель, перейти в другой проект, нажать Отменить. Проверить все слайды и кадрирование.
6. Переименовать проект, закрыть и открыть приложение. Скачать копию, закрыть сообщение, повторить экспорт. Проверить восстановление на отдельной тестовой установке.
7. В двух тестовых вкладках восстановить копию в одной, попытаться изменить старую ленту во второй: изменение должно быть отклонено.
8. Проверить добавление и перестановку без мерцания, долгий тап и автопрокрутку, удобство стрелок слайдов.

## Публикация и возврат
До согласования не сливать ветку в main. После согласования заменить preview на V3.7.0, обновить README и имя кеша sw.js, повторить целевые проверки и проверить публикацию GitHub Pages.
Обновление не содержит удаления IndexedDB и не повышает версию базы. Старые записи остаются читаемыми V3.6.3. Возврат к сохраненной ветке возвращает код; названия проектов в V3.6.3 не отображаются, но остаются в meta. Возврат кода не заменяет резервную копию фотографий.
