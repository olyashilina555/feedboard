КАК ОБНОВИТЬ СТАРЫЙ САЙТ

1. Открой GitHub → репозиторий feedboard.
2. Вкладка Code.
3. Нажми Add file → Upload files.
4. Загрузи:
   - index.html
   - manifest.webmanifest
   - sw.js
5. GitHub предупредит, что файлы уже существуют — это нормально.
6. Нажми Commit changes.
7. Подожди 1–3 минуты.
8. Открой https://olyashilina555.github.io/feedboard/
9. Если старая версия осталась в Safari — обнови страницу или закрой/открой вкладку заново.

ВАЖНО
V2 использует новую локальную базу. Фото из первой тестовой версии могут не перенестись автоматически.
