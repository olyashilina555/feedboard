FEEDBOARD V3.2

Что изменилось:
- Сохранены все функции V3.1.
- Сохранена прежняя локальная база IndexedDB, чтобы существующие проекты и фото не пропали.
- Перетаскивание публикаций доработано для iPhone / Home Screen PWA.
- При удержании карточки у верхнего или нижнего края экрана включается автопрокрутка.
- Обычный тап теперь открывает крупный просмотр публикации.
- Тип публикации Фото / Карусель / Reel меняется внутри окна просмотра.
- Карусель теперь может содержать несколько фотографий.
- В карусель можно выбрать сразу несколько новых фото.
- Карусель листается свайпом в крупном просмотре.
- Очередность фотографий карусели можно менять стрелками под миниатюрами.
- Первое фото карусели используется как обложка в основной сетке.

КАК ОБНОВИТЬ:
1. GitHub → feedboard → Code.
2. ... → Upload files.
3. Загрузить все 4 файла из этой папки.
4. Оставить Commit directly to main.
5. Нажать Commit changes.
6. Подождать 1–3 минуты.
7. Сначала открыть https://olyashilina555.github.io/feedboard/?v=3.2
8. После проверки открыть Feedboard с иконки на главном экране.

ВАЖНО:
Не очищайте данные Safari / данные сайта ради обновления: фотографии Feedboard хранятся локально в браузере.
