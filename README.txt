FEEDBOARD

Файлы:
- index.html — сам сайт
- manifest.webmanifest — данные для установки как веб-приложение
- sw.js — офлайн-режим после первого открытия

Самый простой запуск:
1. Создай бесплатный аккаунт на GitHub.
2. Создай новый публичный репозиторий, например feedboard.
3. Загрузи в него эти 3 файла.
4. Открой Settings → Pages.
5. Source: Deploy from a branch.
6. Branch: main / root.
7. Сохрани.
8. GitHub даст ссылку вида https://твой-логин.github.io/feedboard/

На iPhone:
1. Открой ссылку в Safari.
2. Нажми Поделиться.
3. Выбери «На экран Домой».
4. Назови Feedboard.
5. Готово.

Важно:
Фото сохраняются локально на конкретном устройстве/браузере.
Если очистить данные Safari, они могут удалиться.
