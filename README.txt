FEEDBOARD V3.5

Что изменилось:
- Сохранены рабочие исправления V3.4.
- Основное перетаскивание ленты и удаление не менялись.
- Добавлена отдельная кнопка «+ Создать карусель».
- Карусель создается сразу из нескольких выбранных фотографий.
- Для новой карусели нужно выбрать минимум 2 фото.
- Все выбранные фото сохраняются как одна публикация-карусель.
- Перестановка фото внутри карусели ускорена.
- После нажатия стрелки порядок визуально меняется сразу, без ожидания полной записи IndexedDB.
- Несколько быстрых перестановок сохраняются одной отложенной записью.
- Если первое фото меняется, обложка карусели в сетке обновляется автоматически.
- Сохранена прежняя база feedboard-v2-db и текущие проекты.

КАК ОБНОВИТЬ:
1. GitHub → feedboard → Code.
2. ... → Upload files.
3. Загрузить все 4 файла.
4. Commit directly to main → Commit changes.
5. Подождать 1–3 минуты.
6. Проверить: https://olyashilina555.github.io/feedboard/?v=3.5

КАК ПРОВЕРИТЬ:
1. Нажать «+ Создать карусель».
2. Выбрать минимум 2 фото сразу.
3. Открыть созданную карусель.
4. Несколько раз поменять порядок стрелками.
5. Закрыть и снова открыть карусель — порядок должен сохраниться.
