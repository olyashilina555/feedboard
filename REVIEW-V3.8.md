# V3.8.0 — прототип видео Reels

Рабочая версия для проверки разработчиком. Основной сайт остается на V3.7.2. Для опыта использовать отдельный тестовый адрес (другой origin, не папку основного сайта) и искусственные проекты. Не открывать прототип поверх рабочей базы: он повышает ее версию с 2 до 3. Старый код не сможет открыть обновленную базу. Возврат ветки — не восстановление пользовательских данных.

В новой версии добавляется только таблица исходных MP4. Публикация хранит ссылку на ролик, обложку и кадрирование. Перестановка и кадрирование не переписывают видеобайты. Фото по-прежнему можно использовать без видео. Ограничения: 24 МиБ на ролик и 96 МиБ видео суммарно. Кодеки должны поддерживаться браузером. Видеокаруселей нет.

Копия без роликов остается JSON. С роликами это файл .feedboard: сигнатура FBV2, размер заголовка, заголовок JSON с фото, затем исходные байты видео. При чтении проверяются длина, контрольные суммы роликов, доступность медиа и структура до замены данных. Старые JSON по-прежнему читаются; старые версии приложения не читают новый контейнер. Хранение, импорт и экспорт локальные.

Автотест video-v38.cjs использует настоящее синтетическое MP4 (H.264/AAC), FFmpeg, программную имитацию браузерных событий и IndexedDB. Проверены переход с предыдущей схемы, чтение после повторного открытия, восстановление тех же байтов, обработка нехватки места и поврежденного видео. Это не испытание нативного видеоплеера на телефоне.

Перед публикацией на отдельном тестовом адресе: iOS Safari / запуск с главного экрана и Android Chrome / установленная версия. Выбрать MP4 со звуком, проверить воспроизведение, паузу, перемотку, полный экран при наличии; выбрать кадр в середине и отдельное фото, независимо кадрировать 3:4 и 9:16; закрыть и открыть. Экспортировать копию, перенести ее на другой телефон, импортировать только в пустую тестовую установку, сверить оба проекта, звук, кадр и порядок. Повторить с почти заполненным хранилищем и несколькими файлами: проверить отказ без частичного сохранения, расход памяти и время. Проверить отдельный переход с непустой V3.7.1. До этого не включать видеопрототип в основную публикацию.
